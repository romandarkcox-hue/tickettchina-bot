# Автопостинг дешёвых авиабилетов

Два канала, один бот:

| Канал | Настройки | Воркфлоу | Посты |
|---|---|---|---|
| @tickettchina (Китай) | `config.toml`, `state.json` | `post.yml` | 9:15–15:45, каждые 30 минут |
| @antalya_istanbul_bilety (Турция) | `config_turkey.toml`, `state_turkey.json` | `post_turkey.yml` | 9:00–16:30, каждые 30 минут |

Первый запуск дня проверяет цены по всем направлениям из настроек и составляет очередь:
самые дешёвые билеты вперемешку с самыми популярными направлениями, плюс самый дешёвый
из Москвы и Петербурга, а в конце — обратные билеты (оттуда домой) по рейтингу поисков.
Каждый запуск публикует один пост из очереди, перед этим перепроверив цену по маршруту.
Запускают будильники cron-job.org (`setup_cronjobs.py`): расписание GitHub опаздывает.
Страховка — «Сторож будильников» (`watchdog.yml`): около 12:00 по Москве проверяет, что
у каждого канала уже есть очередь на сегодня; если нет — пишет в личку и публикует пост сам.
Работает бесплатно на GitHub Actions.

## Настройка (один раз)

1. **Токен Travelpayouts.** Зарегистрируйтесь на travelpayouts.com → Профиль → API token.
   Там же ваш **marker** (партнёрский ID) — впишите его в `config.toml` → `[links] marker`.
2. **Бот Telegram.** В @BotFather: `/newbot` → получите токен.
   Добавьте бота в администраторы канала с правом «Публикация сообщений».
3. **GitHub.** Создайте приватный репозиторий и загрузите эти файлы.
   Settings → Secrets and variables → Actions → New repository secret:
   - `TRAVELPAYOUTS_TOKEN`
   - `TELEGRAM_BOT_TOKEN` (бот Китая), `TURKEY_BOT_TOKEN` (бот Турции)
   - `ADMIN_CHAT_ID` — личный чат для отчётов и сообщений о сбоях
4. Будильники: `python setup_cronjobs.py` (ключи в `.env`).
5. Вкладка **Actions** → воркфлоу канала → **Run workflow**, в поле test_chat — свой чат:
   все посты дня придут сразу в личку.

## Проверка на компьютере

```powershell
$env:TRAVELPAYOUTS_TOKEN="ваш_токен"
python bot.py --dry-run                              # Китай
python bot.py --config config_turkey.toml --dry-run  # Турция
```

Покажет посты, которые были бы опубликованы, ничего не отправляя.
`--next` — один следующий пост из очереди (так работают запуски по расписанию).

## Что можно менять в настройках канала

- `[routes]` — направления (откуда → куда), `[cities]` — названия городов.
- `days_ahead` — на сколько дней вперёд искать вылеты.
- `max_transfers` — максимум пересадок (0 — только прямые рейсы).
- `posts_per_run` — сколько билетов в день (без обратных), из них `cheapest_count` самых дешёвых.
- `featured_origins` — города, из которых всегда добавляется самый дешёвый билет.
- `popularity` — `searches` (рейтинг поисков Aviasales) или `cache` (сколько цен в кэше).
- `reverse_count`, `reverse_max_per_city` — сколько обратных билетов и не больше скольких
  из одного города.
- `hours` — часы публикаций по Москве; время будильников — в `setup_cronjobs.py`.
- `skip_same_ticket_days` — тот же билет (направление + дата + цена) не публикуется
  повторно N дней; вместо него берётся следующий по цене.

Опубликованные билеты и очередь на день бот хранит в `state.json` / `state_turkey.json`.

## Еженедельный отчёт

По понедельникам в 09:30 по Москве бот присылает **в личный чат** (`ADMIN_CHAT_ID`, не в канал)
статистику Travelpayouts за прошедшую неделю: переходы, поиски, покупки, заработок,
лучшие направления по переходам и баланс. Вручную: вкладка Actions → «Еженедельный отчёт»
→ Run workflow, или `python report.py --dry-run` на компьютере.
